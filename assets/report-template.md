# 核查报告模板

用法：复制此结构填写。方括号内为填写指引，产出时删除。

---

## 标题

判断式优先：`事实核查：[被核查对象]并没有[被指称的行为]`

示例：
- 事实核查：这张照片并非 28 岁时的佩洛西
- 事实核查：科学家没有说 X 会导致 Y
- 事实核查：X 没有被逮捕；也没有做 Y

> 中文平台若受字数限制只能写疑问式（`核查｜……？`），须在摘要第一句立即给出结论，抵消疑问式复述错误主张的副作用。

## 判定标签栏（对外发布必备）

标题之下、正文之前，用一行给出总判，再列出各子命题标签的构成。读者只看这一栏就能拿到结论。

```
总判：大部分真实

真实 6 ｜ 大体真实 2 ｜ 需澄清 1 ｜ 误导 1     （共 10 个核查点，截至 2026-09-11）
```

规则：

- 子命题标签**必须逐点给出**，总数对齐核查点数量。
- 措辞克制优先（有据 7 档），不用「假新闻」。
- 含「无法证实」的核查点要单独标出，不能混进其他档里被平均掉。
- HTML 版可用色块呈现：真实/大体真实→绿系，需澄清→琥珀，误导/虚假→红系。

## 时间线（说法含先后顺序时必备）

凡是「A 发布 → 一周后 B」这类含时序要素的说法，**必须画时间线**，用图形把真实顺序摊开。表格是底线，对外发布建议配图。

| 时间 | 事件 | 对本核查的意义 |
|---|---|---|
| YYYY-MM-DD | | 与说法一致 / 与说法矛盾 |

绘图要点：

- 纵轴按时间正序，把**说法宣称的顺序**与**证据还原的顺序**并排或对照呈现。
- 标出说法声称的因果箭头，与证据支持的方向对比（本案即「先停滞→后改名」被说成「先乐观→后打脸」）。
- 时间线里出现的每个日期都要有出处。

## 摘要

[被核查的传言内容，一句话。]经核查，[结论]。 [得出该结论的 2–3 句话，交代关键证据。]

示例：中文网络流传一张据称是芬兰女议员在欧安组织会议上对俄罗斯代表团竖中指的照片。经核查，照片是后期篡改的，竖中指部分被 PS 进去。照片中的女士并非芬兰女议员，而是美国常驻联合国代表萨曼莎·鲍尔；场合并非欧安组织会议，而是联合国安理会 2014 年 3 月 15 日的一次紧急会议。

## 写作检查表

- [ ] 结论有截止时间
- [ ] 判定标签栏已给出，子命题标签数与核查点数一致
- [ ] 含先后顺序的说法已画时间线，并对照了说法宣称的顺序
- [ ] 每条证据有链接或明确出处
- [ ] 关键信源在付费墙后时，已声明各细节的取证层级（L1/L2/L3/L4）
- [ ] 至少 2 个独立信源（除利益相关方否认外）
- [ ] 无匿名来源
- [ ] 未把「搜不到」写成「虚假」
- [ ] 未用疑问式标题复述错误主张
- [ ] 原文为外文时已回原文核对，未只依赖译文
- [ ] 虚假内容引用的是存档链接而非原始链接
- [ ] 未使用「假新闻」一词（除非引号引用）
- [ ] 未表达个人观点与立场
- [ ] 涉及真人时已评估隐私与伤害风险
- [ ] 报告发布前已经过至少一轮非作者编辑复核
