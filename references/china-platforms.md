# 中文平台与国内一手信源

适用场景：说法在微信、微博、抖音、快手、小红书、知乎、B 站、头条等中文平台流传，或涉及中国境内的政策、法律、统计、企业、司法、药品等事实。

平台功能与规则会调整，本文截至 2026-10。具体按钮位置与修改上限以平台当前界面为准。

## 1. 先分清「谁发的」

中文平台上最常见的误判，是把**平台上的自媒体账号**当成**平台所属的媒体机构**。

| 看到的写法 | 实际可能是 | 怎么查 |
|---|---|---|
| 「据网易」「据搜狐」「据腾讯」 | 网易号 / 搜狐号 / 企鹅号上的个人或机构自媒体 | 打开原文看作者栏与账号主页；手册里「中文网文 → 俄《真理报》引『据网易』→ 微博」的出口转内销闭环就起于此 |
| 「据百家号」「据头条」 | 百家号、头条号作者，不是百度或字节的新闻编辑部 | 同上 |
| 「XX 发布」「XX 警方」「XX 头条」 | 可能是官方账号，也可能是仿冒号或营销号 | 看认证主体全称；去该机构官网找官方账号链接 |
| 蓝 V / 企业认证 | 只说明是机构注册，不说明是新闻媒体 | 看认证主体；新闻资质可参考国家网信办公布的互联网新闻信息稿源单位名单 |
| 「某群流出」「内部消息」「知情人士」 | 匿名信源 | 按铁律第 4 条处理：不作为证据，通常判「无法证实」 |

## 2. 各平台的取证要点

依据《互联网用户账号信息管理规定》（国家网信办，2022-08-01 施行），主要平台在账号页与内容页展示 **IP 属地**（省级或国家/地区级），公众账号还要展示运营主体等信息。IP 属地可作线索（例：自称「现场亲历」的账号 IP 属地在另一个省），但它反映的是发布时的网络出口，用了代理或人在外地都会偏，**不能单独作为证伪依据**。

| 平台 | 时间与修改痕迹 | 取证要点 |
|---|---|---|
| **微信公众号** | 文章页显示发布时间与 IP 属地；已发布文章允许有限修改（字数、图片数有上限），截图与现页可能有细微出入 | 点公众号名称看账号主体与认证信息；被删文章会显示「该内容已被发布者删除」或「此内容因违规无法查看」，两者含义不同，前者是作者删，后者是平台处理；公众号文章外部搜索引擎覆盖差，用微信「搜一搜」 |
| **微信群 / 朋友圈** | 无公开时间戳 | 封闭渠道，无法溯源到群内首发。改为：①核查说法本身 ②在开放平台搜同一段文字最早出现在哪里。请用户提供截图（含时间）或原始转发文本 |
| **视频号** | 发布时间、IP 属地 | 常见「搬运 + 重配音」；截帧反搜找外网原片 |
| **微博** | 时间戳精确到分钟；可编辑，编辑过的会有标记并可看编辑记录 | 看认证类型与认证主体；看评论区与转发链上游；热搜历史需第三方存档站，只作线索 |
| **抖音 / 快手** | App 内常显示相对时间（「3 天前」），网页版可看具体日期；IP 属地 | 二次剪辑、搬运极多，先找原作者（看画面水印 ID、片尾、评论区「原视频在哪」）；注意平台加注的 AI 生成提示（作者自主声明或平台识别添加） |
| **小红书** | 发布时间、IP 属地，有「编辑于」标记 | 图片多经滤镜与裁剪，反搜前尽量取原图 |
| **知乎** | 回答同时显示「发布于」与「编辑于」 | 「编辑于」晚于事件发生不能证明「发布时就知道」；用存档看早期版本 |
| **B 站** | 发布时间；视频标注「自制」或「转载」 | 转载视频看简介里的原出处；弹幕和评论区常有人贴原片链接 |

**存档**：微信、抖音等页面外部存档（archive.org / archive.today）常失败。改用完整截图（必须带上网址或账号名、发布时间、IP 属地）+ 录屏，并记录取证时间。

**AI 生成内容标识**：《人工智能生成合成内容标识办法》（网信办等四部门，2025-09-01 施行）与强制性国家标准 GB 45438—2025 要求生成服务在内容上加**显式标识**（可感知的文字、声音、图形）并在文件元数据中加**隐式标识**，传播平台须核验并提示。用法：

- 有标识 → 强线索，说明来自合规生成服务。
- 无标识 → **不能证明不是 AI**：境外工具不受此约束，标识也可能被截掉或去除（办法禁止去除，但不能阻止）。
- 反过来也要警惕：真实视频被人为加上 AI 水印，用来「证明」某事件是假的。

## 3. 官方信息怎么读

### 警情通报 / 情况通报

1. **回发布主体核对**：网传「通报」截图，先去对应公安机关或政府的官方微博、公众号找原文。找不到原文的截图，按冒名顶替类排查。
2. **看措辞的确定程度**：「经初步调查」「目前」「正在进一步调查」说明不是最终结论，报告里要原样保留这一限定，并留意后续通报。
3. **看是否有更新**：同一事件常有第二、第三份通报修正前一份，按时间排序后引用最新一份，并说明变化。

### 红头文件

伪造公文是高频谣言。按《党政机关公文格式》（GB/T 9704—2012）核对：

- 发文字号年份用六角括号：`X 发〔2024〕N 号`。用方括号 `[]` 或圆括号 `()` 是常见破绽（不是决定性证据，部分基层单位也会写错）。
- 发文机关、成文日期、印章位置是否符合格式。
- **最终以发文机关官网或政府信息公开平台能否查到为准**。查不到不等于假，可以写「在 XX 官网未检索到该文件」，并联系发文机关核实。

### 官方辟谣

- 中国互联网联合辟谣平台（https://www.piyao.org.cn/）、各地网信办、公安机关的辟谣可以作为信源。
- 但当辟谣对象**就是发布机构自身**（「本局没有发过这个文件」「本单位不存在此事」）时，它属于**当事方否认**，按 Step 5 规则需要其他独立证据配合，不能单独作为证伪依据。
- 辟谣本身也可能有误或只辟一部分，引用时写清它具体否认了哪一句。

### 直接联系

12345 政务服务热线、机构官网的联系方式、政府信息公开申请（依《政府信息公开条例》）都是有效的「联系当事方」渠道。记录联系时间、对象、答复原文。

## 4. 一手数据库

优先用官方库；商业聚合平台（天眼查、企查查等）只用来定位，最终回到官方来源。

| 领域 | 一手来源 | 说明 |
|---|---|---|
| 法律法规 | 国家法律法规数据库 https://flk.npc.gov.cn/ | 全国人大常委会办公厅维护，含现行有效与已废止版本 |
| 政策文件 | 中国政府网政策库 https://www.gov.cn/zhengce/ ；各部委官网 | 核对文件全文与发布日期 |
| 统计数据 | 国家统计局 https://www.stats.gov.cn/ ；国家数据 https://data.stats.gov.cn/ | 统计公报、年鉴、指标解释（口径说明见 `numbers-and-stats.md`） |
| 企业信息 | 国家企业信用信息公示系统 https://www.gsxt.gov.cn/ | 登记状态、股东、行政处罚 |
| 上市公司 | 巨潮资讯 https://www.cninfo.com.cn/ ；港交所披露易 https://www.hkexnews.hk/ | 公告原文 |
| 裁判文书 | 中国裁判文书网 https://wenshu.court.gov.cn/ | 2021 年后公开量大幅下降，**查不到不代表没有判决** |
| 典型案例 | 人民法院案例库 https://rmfyalk.court.gov.cn/ | 2024-02 上线，收录最高法审核的参考案例，非全量 |
| 失信与执行 | 中国执行信息公开网 https://zxgk.court.gov.cn/ | 失信被执行人、限制消费 |
| 药品与器械 | 国家药品监督管理局 https://www.nmpa.gov.cn/ 「数据查询」 | 批准文号、注册证；区分「药品」「保健食品」「医疗器械」 |
| 医保 | 国家医疗保障局 https://www.nhsa.gov.cn/ | 医保目录、谈判药价格；注意「药价」≠「报销后自付」 |
| 国家标准 | 国家标准全文公开系统 https://openstd.samr.gov.cn/ | 强制性标准可在线读全文 |
| 地图街景 | 百度地图全景、高德地图、天地图 https://www.tianditu.gov.cn/ | Google 街景不覆盖中国大陆，境内地理定位改用这些 |
| 反向图搜 | 百度识图、搜狗识图 | 中文网络图源补充，与 Google / Yandex / TinEye 一起用 |
| 学术 | 知网、万方 | 中文论文；预印本与会议摘要同样要标注 |

## 5. 中文场景高发套路 → 首选动作

| 套路 | 首选动作 |
|---|---|
| 旧闻翻炒，配「刚刚」「突发」 | 找该事件最早报道日期；看画面季节、车牌样式、店招是否与「现在」吻合 |
| 外网视频配中文 AI 解说、换地点 | 截帧反搜（含 Yandex），找原片发布地与时间 |
| 伪造通报、红头文件、聊天记录截图 | 回发布主体官方账号核对；截图里的账号名、头像、时间格式与真实界面比对 |
| 「据网易 / 百家号」被外媒引用后再出口转内销 | 沿引用链逐级回溯到第一个中文自媒体原帖 |
| 「XX 国已禁止 / 批准」 | 回该国监管机构官网原文，核对批准范围（如加拿大非处方药 ≠ 新冠药） |
| 境外报道被断章取义翻译 | 回外文原文，见 SKILL.md Step 4 第 3 条 |
