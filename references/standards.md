# 职业准则与机构流程

来源：《事实核查手册》第2章（IFCN 与欧洲 EFCSN 准则，p39–68）、第3章（法新社风格手册、台湾事实查核中心与 Health Feedback 流程）。

## 1. IFCN 与 EFCSN

| 项 | IFCN 国际事实核查网络 | EFCSN 欧洲事实核查标准网络 |
|---|---|---|
| 官网 | https://www.poynter.org/ifcn/ | https://efcsn.com/ |
| 背景 | 2015 年由 Poynter 研究院创立；2016-09-15 发布全球首个事实核查准则 | 2022-09-15 发布欧洲准则；6 家欧洲组织牵头，欧盟委员会支持 |
| 重认证周期 | **每年** | **每两年** |
| 适用范围 | 事实核查机构 | 事实核查 + 明确纳入 **OSINT 组织** |

原文评价：欧洲准则基本涵盖 IFCN 关于方法论、伦理、透明度的规范与精神，但表述更具体、更完整。

## 2. 可勾选职业准则清单

### 一、非党派与公正

- [ ] 对同等主张使用相同的高标准证据，不将核查过度集中于任一方
- [ ] 考虑核查内容的影响范围与重要性，并在网站说明选题理由
- [ ] 存在相关利益（含消息源、商业关系）须披露
- [ ] 机构不与任何政党/政治人物/候选人关联，不宣布支持，不对任何政策立场持倡导或反对态度
- [ ] 网站列明员工无党派政策；员工不参与倡导或公开发表观点
- [ ] （欧洲）禁止雇佣在政党/政府/国有公司担任受薪要职者；禁止接受超常规优惠礼物；仅可倡导与自身使命相关的议题且须公开准则

### 二、信源公开与透明度

- [ ] 提供所有重要证据来源的细节（网络内容给链接）以便读者复现；危及安全时给尽可能多的细节
- [ ] 优先使用最佳一手信源；无合适一手须解释为何用二手
- [ ] 关键内容使用两个或更多具名来源，除非只有一个相关
- [ ] （欧洲）匿名来源的信息须由实名来源或实物证据证实方可使用
- [ ] 识别并说明消息源存在的利益
- [ ] ⚠ 警示信号：常无理由依赖匿名/单一/二手来源；常把二手呈现为一手；未识别利益

### 三、资金与组织透明度

- [ ] 资金来源透明；占上年总收入 **5% 以上**（欧洲：超 **1% 或 5000 欧元**）的每个来源详细说明
- [ ] 公布组织法律形式、所有权隶属、组织架构、谁行使编辑控制权
- [ ] 列出关键人物职业履历；明示用户沟通途径
- [ ] ⚠ 警示信号：隐瞒具有重要控制权者的身份；使用化名；公布虚假地址

### 四、方法论公开与标准

- [ ] 网站发表选择/研究/撰写/发布的方法声明；使用评级须解释定义
- [ ] 相似内容按相同标准评估证据，不论提出者是谁
- [ ] 列出支持与不支持被核查说法的证据
- [ ] 鼓励用户提交核查请求，并说明哪些可查哪些不可查
- [ ] 尽量联系主张提出者寻求支持证据（网络内容常不可行；未回复不妨碍核查；安全理由可不联系）
- [ ] （欧洲）每项调查发布前至少经**一轮非作者编辑**
- [ ] （欧洲）使用精确、事实性、不带情感的语言，不夸大结论；报告对公共利益的影响
- [ ] ⚠ 警示信号：常无证据假设发布者意图；常不经核实接受任何来源；常未检查方法即接受数据/研究；常含倾向性语言

### 五、更正政策

- [ ] 有易查看的更正/投诉政策，明确涵盖与不涵盖的内容、重大错误的处理方式、可不回应投诉的情形
- [ ] 有可靠证据证明确需更正时，公开透明更正，并确保原读者能看到更正版
- [ ] IFCN 签署方页面告知可向 IFCN 举报并附链接；媒体下属部门须母公司也有此政策
- [ ] （欧洲）同一出版物附更正说明（仅排版/语法/风格错误可免说明）
- [ ] （欧洲）无法编辑原版时以同格式渠道传播更正
- [ ] （欧洲）实质性错误须解释成因
- [ ] （欧洲）新增信息以更新说明告知；首申提供上年更正记录，更新申请提供前两年
- [ ] （欧洲）提供更正请求的直接渠道；年度内部审查更正；不服可申请独立审查

### 六、隐私与安全（欧洲特有）

- [ ] 有合理安全担忧时，对调查对象图像/身份做模糊处理
- [ ] 用户生成虚假信息时，避免来源或身份过度曝光
- [ ] 谨慎识别未成年人并保护其隐私
- [ ] 对可能招致骚扰的个人信息匿名化（遮盖电话/证件/银行/邮箱等）
- [ ] 适当时向被点名者提供回应权

### 七、选题标准（资格与公共利益）

- [ ] 合法注册、专门从事事实核查的独立机构或团队
- [ ] 定期核查公共利益相关内容，发布无党派偏见的报告
- [ ] 编辑不受国家/政党/政治人物控制（从国家或政治来源获资须声明如何确保资助不影响结论）
- [ ] 申请前 6 个月（所在国已有 ≥5 签署方则 12 个月）平均每周至少一篇报告；≥75% 核查聚焦公共利益
- [ ] （欧洲）上级组织须遵循总体道德精神

### 八、证据标准

- [ ] 核查结果须由高质量信源支持并交叉验证（欧洲）
- [ ] 以准确、事实性的语言发布

### 两准则差异汇总

| 项 | IFCN | EFCSN |
|---|---|---|
| 重认证 | 每年 | 每两年 |
| 覆盖 | 事实核查机构 | 额外明确纳入 OSINT |
| 财务披露阈值 | 5% | 1% 或 5000 欧元 |
| 匿名源 | 尽量提供细节、披露利益 | 须由实名源或实物证据证实 |
| 独有要求 | — | 隐私与安全章节、上级组织道德精神、发布前至少一轮非作者编辑、实质性错误须解释成因、年度审查更正 |

## 3. 法新社（AFP）风格手册要点

https://factcheck.afp.com/afp-fact-checking-stylebook

**使命**：核查广泛流传并对新闻或公共讨论产生重大影响的谎言、恶作剧与误导性说法；**优先核查可能造成伤害的虚假说法**；保持平衡，不集中针对某一候选人/政党/网站，除非其为有害虚假信息的一贯传播者；准确性最重要，透明解释方法同等重要；错误必须立即且透明地纠正。

按字母序的可执行要点：

| 条目 | 要求 |
|---|---|
| 指控（ACCUSATIONS） | 可以说帖子是虚假的，但必须同时指出真实情况（如「A 国确实轰炸了 B 国，但这张图来自 C 国早期冲突」），不要让人以为在否认真实攻击 |
| 匿名消息来源 | **不得引用匿名消息来源**；仅愿以头衔引用者，须由部门负责人决定 |
| 出处（ATTRIBUTION） | 所有引用事实必须有清晰明确的出处 |
| 偏见（BIAS） | 注意确认偏误：一旦认定是假的，会忽略相反证据 |
| 背景（CONTEXT） | 高度重视背景，可链接已发布的可靠来源；孤立的事实核查会误导读者 |
| 更正 | 事实性错误必须更正并在原版注明「更正」+ 日期 + 解释；严重错误撤稿并解释；新证据用「更新」 |
| 否认（DENIALS） | **不要仅凭当事人/组织的否认来证明说法虚假**，必须提供其他独立证据 |
| 术语 | 虚假信息 disinformation=故意误导；错误信息 misinformation=无意造成；**避免使用「假新闻 fake news」**，除非引号引用 |
| 注意义务/减少伤害 | 对有责任关心报道对象，尽量减少伤害；可能模糊面部或隐去身份；涉及未成年人尤其谨慎 |
| 未来事件 | **不对尚未发生事件的预测做核查**（科学类例外，如小行星撞地球的虚假末日帖，可引天文学家） |
| 图形图像 | 使用前自测：是否对理解核查内容至关重要？公众有权知道吗？是否只是满足病态好奇？是否考虑了受害者及家属？ |
| 骚扰 | 核查员可能成为网暴与人肉目标，需预防措施；参考 Rory Peck Trust 数字安全准则 |
| 标题图片 | 尽可能用误导性或虚假的图片做头图，并明确标明结果；不要用真事件图做头图以免混淆 |
| 标题 | 简短、清楚说明事实、能与头图分开独立存在；**写具体事实而非否定式**（「这张 2014 年的图片拍摄于巴黎，不是伦敦的反水力压裂抗议」优于「这不是伦敦反水力压裂抗议的图片」）；包含关键词与专有名词便于搜索 |
| 健康 | 避免表述被理解为 AFP 认可某药物/疫苗的功效或安全性；用权威来源归因（WHO、FDA 等）；避免「疫苗不会导致 XXX」这类确定性表述；避免「没有相关研究」这种绝对说法，改说「搜索了备受尊重的科学出版物数据库，未发现……」；注明证据搜集日期 |
| 图片 | 证实为合成图时，报告中**同时发布**：①合成后的成片 ②未被修改的原图 ③用于提取元素的另一张图 |
| 影响与范围 | 需解释虚假信息的影响（各平台分享与浏览量、发布者粉丝数）；**没有数据支持不得使用「广为流传」「热帖」**；分享数给约数；同一内容多次出现即使单条分享少也可累计判断为火爆；不要只盯 Facebook/Twitter，也要涉及 WhatsApp/Signal/Telegram 等闭合式通讯应用 |
| 调查 | 说明图片如何被溯源、核查如何进行；标准是**读者能看懂核查如何完成，甚至自己按同样步骤复现** |
| 篇幅 | 清楚简洁但不牺牲完整性；不读全文的人只看标题和头图，所以头图必须清楚显示核查结果 |
| 长视频/纪录片 | 可核查其关键要素作为说明；虚假内容常包裹在已证实事实的外壳下，需表明有足够错误信息使整个前提不可信 |
| 分享数 | 给约数（「超过 500 次」）；说明内容已在网上流传多久（旧内容可能被当下事件重新翻出） |
| 其他事实核查机构 | **不作为主要消息来源**；若引用须先自行核实并注明；不同方法得出相同结论也可引用 |
| 其他媒体 | 尽可能链接自家内容；否则链接被视为可靠信源的当地媒体；避免链接付费墙内容 |
| 观点 | 不对观点做事实核查 |
| 宣传（PROPAGANDA） | 定义为政治等行为者蓄意影响人们思维与行为，可能基于捏造或夸大，有偏见和误导性，**但不一定都是虚假的** |
| 引语/虚假陈述 | 核查两类：①公众人物发表的不符事实的陈述 ②被指为公众人物发布但实为捏造或歪曲的陈述。**只有拿到原始版本（录音、官方记录）才能核查其陈述，不得基于其他媒体或社媒的转引**。歪曲类须找到原始引文并说明如何被编辑；捏造类须取得本人或发言人否认并自行调查；避免「他/她从未说过」，改说「官网和媒体上没有该陈述的踪迹，其发言人已坚决否认」 |
| 重复错误主张 | 不传播虚假信息。**真相三明治**：先说真相 → 提及虚假信息 → 再说真相 |
| 讽刺/笑话 | 只在被大量分享或互动时才重点关注；明显荒谬时不要让机构显得在严肃对待；但一种文化中的明显荒谬在另一种文化中未必 |
| 截屏 | 截图须显示帖子基本内容，剪裁时不得遗漏分享与互动数 |
| 消息源 | 标明姓名、年龄、头衔、职业、隶属、资历；引用专家须具体说明资历；**除利益相关方否认外，每次核查至少两个独立消息源**；直接联系消息源，但与已知虚假信息传播者联系可能招致骚扰，须慎重 |
| 翻译 | 每个翻译都须适应当地/区域环境，必要时补充其他消息源与背景 |
| 写作 | 直白、实事求是，不用华丽修辞；避免双关与讽刺（跨文化无法转换）；**每个事实不仅应真实，还必须被证明是真实**：给证据（链接、嵌入帖子/视频、街景地图）、解释调查步骤（说明用了 Google 反向图搜、InVID 等工具）、简明扼要；**链接虚假内容时给网络存档链接而非原始链接**（perma.cc / Wayback Machine / Archive Today） |

## 4. 台湾事实查核中心作业流程

https://tfc-taiwan.org.tw/about/principle

**选题 7 条标准**：
1. 是否符合优先查核对象（重要公共事务相关的争议或疑似错误信息）
2. 是否属于可查核的事实（**不查核意见**，仅查核预期可被验证为正确或错误的事实）
3. 对社会的意义为何
4. 对社会的影响为何
5. 传播状况如何
6. 是否在中心查核能力所及（有价值但能力不足者先纳入关注对象）
7. 是否已被中心查核过（曾查核者除特殊意义外不列为优先，以确保选题多元与平衡）

**作业准则要点**：以公开、透明、严谨、负责为原则；每日查核项目由查核会议决定；报告公布前**至少须经三位查核人员（含主管）核校**，并经总编审同意；必要时咨询咨询委员、学者专家并向当事人求证；结果一般分为正确、部分错误、错误三级；资料公开供外界核对；开放外界申诉，查核人员须严谨复查，确有错误立即更正公布。

## 5. Health Feedback 工作流程

https://healthfeedback.org/process/

1. **选择**：选在社交媒体上最流行、或在拥有大量读者的媒体上发表、且含有科学上可验证主张的文章。
2. **邀请审稿人**：负责监督核查过程的编辑邀请相关专家。
3. **文章分析**：审稿人评估其推理所依据的事实是否与最新科学知识一致；应代表科学文献的知识现状，使用得到有力支持的理论与观察，避免片面/孤立/仅微弱支持的证据。审稿人还应：添加相关信息与背景；评估科学推理（误导性论点往往不是基于错误事实，而是基于有缺陷的推理或隐藏假设）。
4. **评估**：按上述「可信度标准」（事实准确性、科学认识、背景和限制、逻辑/推理、精确度/清晰度、信源质量、公平性/客观性）打分（+2 至 −2，见 `verdicts.md`）。
5. **总结与反馈**：编辑把科学家最突出的观点写成总结并推广，同时向被核查文章的媒体编辑提供反馈。
