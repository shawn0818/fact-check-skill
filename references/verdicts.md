# 各机构评级体系对照

来源：《事实核查手册》第3章「事实核查结果的判定」（p144–173）。跨机构引用时注意：**同一说法不同机构可能给出不同标签**，这是评级系统的固有局限，非错误。

## 1. 四大类型

| 类型 | 代表 | 说明 |
|---|---|---|
| 文本 | 有据、法新社 | 基于一组表示真实性的词语 |
| 图像 | 华盛顿邮报（匹诺曹）、PolitiFact（Truth-O-Meter） | 用图标表达真实程度 |
| 颜色 | ColombiaCheck | 红=假、橙=误导、绿=真实 |
| 数字 | 部分机构 | 打分 1–5 或 1–10 |

**不使用评级系统的机构**：英国 Full Fact。理由（原文）：评级在某些情况下过度简化，不能完全传达核查结果的细微差别；一项主张常常既不是简单真也不是简单假，而是缺少重要背景。Full Fact 主张不具对抗性、更具协作性的方法。

## 2. 有据（7 档）

| 标签 | 定义 |
|---|---|
| 真实 | 根据目前公开的最佳证据，该说法准确，且没有遗漏任何重要内容 |
| 大部分真实 | 含真实要素，但要么不完全准确，要么需要澄清 |
| 部分虚假 | 说法中既包含真实信息，也包含虚假内容 |
| 误导 | 信息片面、过期、挪用或标题党等等，导致受众产生错误理解 |
| 大部分虚假 | 说法的主要部分是虚假的，尽管有微小部分真实 |
| 虚假 | 根据目前公开的最佳证据，该说法不准确 |
| 无法证实 | 目前公开的证据既不能证明也不能证伪，需要更多研究 |

**使用经验（重要）**：
- 初始评级还用过「片面」「过期」「错误引用」，后期**已删除**；后期更审慎使用「部分虚假/大部分虚假/部分真实」，**提高「误导」的使用频率**并写清原因。
- 局限：「大部分虚假」与「部分虚假」之间无法用定量标准区分（65% 假 vs 35% 真有什么差别？）；多个核查点捆绑成一个总评级会导致误读；不同核查员之间一致性难保证；不同机构对同一传言可能给出不同评级。
- 因此当说法含多个核查点时，**逐点给标签**，总标签仅作提示。

### 争议案例 1：美国宇航员破坏联盟号（评级从「片面」改为「无法证实」）

- 说法：NASA 宇航员 Serina Auñón-Chancellor 在太空情绪崩溃，损坏联盟号以便早日返回。
- 证据：俄方（塔斯社 2021-08-12，引匿名官员）指控为主；美方（NASA 载人航天负责人、局长）否认。
- 关键事实：space.com 指出空间站有监控设备，NASA 官员在泄漏前与泄漏开始时就掌握美国宇航员确切位置，视频显示无人靠近俄方舱段；但俄方称美俄交界处摄像机没工作；**无第三方机构确证**。
- 最初判「片面」（仅采信俄方陈述、无美方回应），读者反驳后重审证据，改判「无法证实」。

### 争议案例 2：拜登外交政策 5 点（评级「部分虚假」的信息损失）

- 5 个子命题中：2 点真实、1 点有误导性、2 点虚假 → 总评为「部分虚假」。
- 但微信标题受字数限制只覆盖其中两点（而这两点实际是**虚假**的），读者只看标题与「部分虚假」图标，会误以为这两点只是「部分虚假」。

## 3. PolitiFact — Truth-O-Meter（6 档）

https://www.politifact.com/article/2018/feb/12/principles-truth-o-meter-politifacts-methodology-i/

| 等级 | 定义 |
|---|---|
| True 真实 | 陈述准确无误，无重大遗漏 |
| Mostly True 大部分真实 | 准确，但需澄清或补充 |
| Half True 部分真实 | 部分准确，但遗漏重要细节或断章取义 |
| Mostly False 大部分虚假 | 含真实成分，但忽略关键事实 |
| False 虚假 | 不准确 |
| Pants on Fire | 不准确，且是荒谬的说法 |

**举证责任在发言者**；核查员按说法发表时已知的信息评级。

**评级流程**：记者提出评级建议 → 与指定编辑共同审阅并达成一致 → 提交另两名编辑 → 三人与记者讨论四个问题（字面意思是否正确？是否有另一种读法？提出者是否举证？历史上如何处理类似陈述？）→ 三名编辑投票（两票决定）→ 定稿发布。

## 4. 华盛顿邮报 — 匹诺曹

https://www.washingtonpost.com/politics/2019/01/07/about-fact-checker/

| 等级 | 定义 |
|---|---|
| 1 个匹诺曹 | 对事实有遮掩、选择性说真相、有遗漏和夸大，但无彻头彻尾的谎言。大部分真实 |
| 2 个匹诺曹 | 重大遗漏和/或夸大；靠文字游戏与法律语言制造虚假误导印象。半真半假 |
| 3 个匹诺曹 | 重大事实错误和/或明显矛盾，大部分虚假；可能含技术正确但断章取义的陈述 |
| 4 个匹诺曹 | 弥天大谎 |
| 倒立匹诺曹 | 双重标准式指责（例：麦康奈尔抱怨民主党用高度党派化策略，却拒不承认自己也用过） |
| Geppetto 复选标记 | 真实（Geppetto 是匹诺曹的创造者） |
| 无底线匹诺曹（Bottomless Pinocchio） | 政客拒绝放弃已被评为 3–4 个匹诺曹的说法并不断重复，基本变成虚假信息与宣传 |

## 5. Snopes（19 类）

https://www.snopes.com/fact-check-ratings/

Research In Progress / True / Mostly True / Mixture / Mostly False / False / Unfounded / Unproven / Outdated / Miscaptioned / Correct Attribution / Misattributed / Legend / Scam / Legit / Labelled Satire / Originated as Satire / Recall / Lost Legend (TRoLL)。

## 6. 台湾事实查核中心

- 作业准则第七条：一般分为**正确、部分错误、错误**三级，并得就特殊状态需要另为裁定。
- 官网评级页面：https://tfc-taiwan.org.tw/node/5866 （另见「事实厘清」「证据不足」等扩展级）
- 流程要求：报告公布前至少经三位查核人员（含主管）核校，经总编审同意后发布；资料公开供外界核对；开放外界申诉。

## 7. Meta（脸书）平台评级

https://transparency.fb.com/zh-cn/features/content-ratings-fact-checkers-use/

虚假内容 / 编辑过的内容 / 部分虚假 / 缺少背景信息 / 讽刺内容 / 真实内容。Meta 设准则，事实核查机构独立评定。

**时效更新（2026-10）**：Meta 于 2025-01 宣布在**美国**终止第三方事实核查项目，改用社区注释（Community Notes），美国境内帖子不再加第三方核查标签；美国以外地区的第三方核查项目按 Meta 当时表态继续运行。2026-03 Meta 监督委员会认为社区注释不能替代全球范围的事实核查。截至本次修订未见全球推广或终止境外合作的正式公告，引用前请核对最新状态。

## 8. 法新社标准术语（写作时用词）

| 术语 | 含义 |
|---|---|
| False 虚假 | 多个可靠信源证伪了该说法 |
| True 真实 | 多个可靠信源证实了该说法 |
| Misleading 误导 | 使用了真实信息（文字/照片/视频），但断章取义或与错误背景混合 |
| Altered Photo 篡改照片 | 照片被篡改，具欺骗性 |
| Altered Video 篡改视频 | 视频被篡改，具欺骗性 |
| Missing Context 缺少上下文背景 | 说法是真实的，但没有进一步信息可能有欺骗性 |
| Satire 讽刺 | 说法是虚假的、可能愚弄受众，但无欺骗意图（幽默、戏仿） |

## 9. Health Feedback（医学类，±2 分）

https://healthfeedback.org/process/

| 分 | 含义 |
|---|---|
| +2 非常高 | 几乎无不准确，公平代表科学现状，含适当参考；讨论成本、风险、副作用，不夸大益处；不以因果陈述描述观察性研究 |
| +1 高 | 无重大科学错误，结论来自所提供证据；对干预至少尝试说明风险收益比 |
| 0 中性 | 无重大错误，但洞察力不足 |
| −1 低 | 含重大科学错误或误导性陈述；险些炒作或制造恐惧但仍有平衡 |
| −2 非常低 | 关键事实有重大科学错误、遗漏重要信息、或推理有逻辑缺陷；可能给绝望患者虚假希望或造成不必要伤害 |
| n/a | 不建立在可验证科学信息之上（政策、政治、观点） |

最终评级取所有审稿人平均值；**审稿人基本不同意时不发布评级，核查被认定为「有争议的」（debated）**。

评估维度（可复用的检查表）：事实准确性、科学认识、背景和限制、逻辑/推理、精确度/清晰度、信源质量、公平性/客观性。

常用批评术语（可用于描述误导手法）：不准确、误导性、偏见、有缺陷的推理、以偏概全（cherry-picking）、夸大其词、不适当的信源、不准确/不清晰、标题党、将事实和观点混为一谈、缺乏背景、未披露的利益冲突、歪曲来源、夸大科学信心。
