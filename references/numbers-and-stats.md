# 流程卡：数字与统计类说法

适用场景：说法的核心是一个数字、比例、排名、增长率、倍数或对比（「涨了 300%」「是美国的 5 倍」「每 10 人就有 1 人」「全球第一」）。

数字说法很少是凭空编的，更常见的是**数字本身对、口径或比较方式错**。所以重点不是「这个数存不存在」，而是「这个数在原始出处里是什么意思」。

## 第一步：找到数字的原始出处

逐项填清，填不出来的就是待查项：

| 项 | 例 |
|---|---|
| 谁测的 | 国家统计局 / 某咨询公司 / 某论文作者 |
| 测的是什么（定义） | 城镇调查失业率，而非登记失业率 |
| 什么时间、什么范围 | 2025 年全年，全国城镇 |
| 怎么测的 | 抽样调查 / 行政登记 / 模型估算 |
| 单位 | 万人、亿元、千立方米 |
| 原文原句 | 引原文，不引转述 |

找不到原始出处、只有「据统计」「数据显示」→ 该数字按「无法证实」处理，除非另有一手数据可复算。

## 第二步：口径检查清单

逐项过，命中任意一项都要在报告里写明。

**比较方式**

1. **百分比 vs 百分点**：利率从 2% 到 3%，是上升 1 个百分点，也是上升 50%。两种写法都对，但混用就错。
2. **相对风险 vs 绝对风险**：「风险增加 50%」可能只是从万分之二到万分之三。健康类说法必须同时给出绝对数。
3. **同比 vs 环比**：季节性强的数据（消费、旅游、用电）用环比比较会失真；看是否季节调整。
4. **基数**：从 1 个到 4 个也是「增长 300%」。小基数的高增长率要同时给出绝对值。
5. **总量 vs 人均**：人口差几倍的国家，比总量还是比人均，结论可能相反。
6. **平均数 vs 中位数**：收入、房价、财富这类偏态分布，平均数会被少数极端值拉高。
7. **名义 vs 实际**：跨年份比较金额要看是否扣除通胀；跨国比较要看用市场汇率还是购买力平价（PPP）。
8. **起止点选择**：换个起点年份，趋势可能反转。看说法是不是挑了最有利的时间窗口。

**定义与范围**

9. **同名不同义**：「失业率」「贫困线」「流感死亡数」「GDP」在不同国家或不同时期的统计方法不同，不能直接比（手册案例：中美流感死亡率统计方法不同）。
10. **范围被换掉**：城镇数据说成全国，某省数据说成全国，某年龄段说成全人群。
11. **价格口径**：药品价格 vs 医保报销后自付；出厂价 vs 零售价；报价 vs 成交价。

**单位与翻译**

12. **量级单位**：英文 billion = 十亿，不是亿；million = 百万。中英互译时数量级出错非常常见。
13. **单位被改**：千立方米写成立方米、万吨写成吨、美元写成人民币。

**来源与样本**

14. **样本代表性**：网络自愿投票、自选样本问卷不能代表总体。看样本量、抽样方法、误差范围。
15. **相关 ≠ 因果**：观察性研究只能说「相关」，说法里出现「导致」「致使」要回原文看研究设计。
16. **区间拼盘**：把不同来源的数字拼成一个区间（「248–290」），实际各来源互不一致。按来源分别列出。
17. **推算数字**：「相差约 N 倍」若原文没有，就是传播者算的，见 SKILL.md Step 2。

**图表**

18. **纵轴截断**：纵轴不从 0 开始，小差异看起来很大。
19. **双纵轴**：两条线用不同刻度，可以人为制造「同步」或「背离」。
20. **只给比例不给分母**：饼图、百分比堆叠图看不出总量变化。

## 第三步：复算

- **用代码算，不心算**。把算式与输入写进报告，读者能照着复现：

```python
# 例：说法称「A 是 B 的约 5 倍」
a_low, a_high = 250, 260      # 原文俄方报价（美元 / 千立方米）
b_low, b_high = 50, 130       # 原文中方口径的两个值
print(a_low / b_high, a_high / b_low)   # 最保守 ≈ 1.9 倍，最极端 = 5.2 倍
```

- 多个合理口径时，给出**范围**，并说明说法挑了哪一端。
- 四舍五入造成的小差异不算错误。

## 判定规则

核心问题：**这个误差是否改变了说法想表达的意思？**

| 情况 | 建议标签 |
|---|---|
| 数字与原始出处一致（含四舍五入），口径也一致 | 真实 |
| 数字准确，但缺少关键背景（只给相对风险、只给增长率不给基数） | 大部分真实，并写明缺什么 |
| 数字本身对，但比较方式或口径让读者得出错误印象 | **误导**，写清误导点 |
| 数字有出入，但量级与方向不变、不影响论点 | 大部分真实 |
| 数字有出入，且改变了论点（量级错、方向反） | 虚假 |
| 原文没有这个数，是传播者推算的 | 单列为子命题，写明计算口径，按推算是否合理判定 |
| 找不到原始出处，也无法从一手数据复算 | 无法证实 |

## 报告写法

- 每个数字都带上：**出处 + 统计期 + 口径**。例：「国家统计局《2025 年国民经济和社会发展统计公报》，2025 年全年城镇调查失业率平均值」。
- 复算过的写出算式。
- 说法挑了极端口径时，把保守口径与极端口径并列，让读者看到差距。
